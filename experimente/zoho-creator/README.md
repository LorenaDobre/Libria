# Experiment Zoho Creator - Libria

## Scop
Realizarea unui catalog demonstrativ de carti printr-o abordare low-code.

## Implementare
Aplicatia Libria Book Catalog System a fost generata cu Zoho Creator.

Functionalitati:
- Formular pentru adaugarea cartilor
- Afisarea cartilor intr-un raport
- Vizualizare Kanban
- Panou de control cu statistici si cautare

## Testare
Au fost generate 5 carti demonstrative.
Am adaugat manual cartea Biblioteca de la Miezul Noptii.
Inregistrarea a fost salvata cu succes.

Total: 6 carti.

## Fisiere
- libria-zoho.ds - definitia aplicatiei Zoho Creator
- catalog-carti.csv - cele 6 inregistrari exportate

## Concluzie
Zoho Creator permite dezvoltarea rapida a unei aplicatii
prin configurare vizuala, fara programare traditionala.

Prototipul a fost comparat cu aplicatia Libria,
dezvoltata in Visual Studio cu Express si PostgreSQL.
